# Mathematical Rules of Thumb: chapter notebooks

Jupyter notebooks for each chapter of *Mathematical Rules of Thumb* by Jason Karpeles. Each notebook includes its figures and saved results, so you can read it here on GitHub without running anything.

Interactive chapter pages: https://karpeles.com/companions/mathematical-rules-of-thumb/

## Run the notebooks yourself

1. Install Python 3.10 or later.
2. Install the packages: `pip install numpy matplotlib jupyterlab`
3. Download this repository (Code, then Download ZIP) or clone it.
4. Run `jupyter lab` in the folder and open any file in `notebooks/`.
